# Tourism Management System

A console-based Tourism Management System developed in C++. This project demonstrates the practical implementation of Object-Oriented Programming (OOP) concepts such as inheritance, polymorphism, encapsulation, abstraction, and file handling.

The system allows users to manage tour packages, flight bookings, customer information, and reservation records through a user-friendly menu-driven interface. Data is stored permanently using file handling techniques, ensuring efficient record management.

## Features
- Add Tour Packages
- Flight Booking Management
- Customer Record Management
- View Reservations
- Modify Booking Details
- Delete Reservations
- Save and Load Data Using Files
- Menu-Driven Interface

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling

This project was developed to strengthen programming skills and demonstrate the use of OOP principles in a real-world tourism reservation system.
